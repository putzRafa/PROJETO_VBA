# VBA_PROJECT

Projeto desenvolvido em **VBA (Visual Basic for Applications)** com o objetivo de automatizar e facilitar atividades realizadas no **Microsoft Excel**.

O projeto surgiu como uma experiência prática com VBA, explorando recursos de automação de planilhas, manipulação de dados, criação de interfaces e geração dinâmica de informações a partir de uma base de dados.

## 📌 Sobre o projeto

O projeto utiliza o VBA para transformar informações presentes em uma planilha de controle em **cards de atividades**, organizados de acordo com os dados cadastrados.

A automação permite trabalhar com informações relacionadas às atividades de manutenção, seus responsáveis e seus respectivos status, tornando a visualização das atividades mais organizada.

Entre os principais conceitos explorados estão:

* Automação de tarefas no Excel;
* Manipulação de células e planilhas através do VBA;
* Leitura e tratamento de dados;
* Criação dinâmica de cards;
* Classificação de atividades por status;
* Utilização de `UserForm` e controles de interface;
* Estruturas de repetição e condicionais;
* Manipulação de strings;
* Interação entre diferentes planilhas;
* Geração de informações de forma automatizada.

## ⚙️ Funcionalidades

O projeto possui funcionalidades voltadas para o gerenciamento e visualização das atividades de manutenção.

### Geração de cards

A partir dos dados cadastrados na planilha, o VBA realiza a criação automática dos cards de atividades.

Os cards são organizados na planilha para facilitar a visualização das informações.

### Classificação das atividades

As atividades podem ser classificadas de acordo com seu status, como:

* **REALIZADO**
* **ATRASADO**
* **EM DIA**

Essa classificação permite identificar rapidamente a situação das atividades cadastradas.

### Seleção de responsável

O projeto possui uma interface para seleção do responsável pela atividade.

Após a seleção, os dados correspondentes são utilizados para gerar a visualização das atividades relacionadas ao responsável escolhido.

### Organização automática

Os cards são distribuídos automaticamente na planilha, evitando a necessidade de criação e organização manual das informações.

## 🛠️ Tecnologias utilizadas

* **Microsoft Excel**

## ▶️ Como utilizar

Para executar o projeto:

1. Baixe ou clone este repositório.
2. Abra o arquivo do Excel que contém o projeto VBA.
3. Caso necessário, habilite a execução de macros.
4. Abra o **Editor do Visual Basic** (`ALT + F11`) para visualizar ou modificar o código.
5. Utilize a interface disponibilizada pelo projeto para selecionar o responsável e executar a automação.
6. Os cards e informações serão gerados automaticamente de acordo com os dados presentes na planilha.

> **Observação:** por utilizar macros, o arquivo deve ser aberto em uma versão do Microsoft Excel que ofereça suporte ao VBA.
